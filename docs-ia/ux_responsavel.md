# UX — Área do responsável (revisão de design)

## Papel no escopo

O responsável **cadastra dependentes** e **recebe avisos** de entrada/saída. Não opera câmera, portaria nem painel administrativo.

## Problemas corrigidos

| Antes | Depois |
|-------|--------|
| Hub “Área 1 / Área 2” (Área 1 recarregava a mesma página) | Home = só lista de dependentes |
| 3 botões Ver / Editar / Avisos por linha | Linha inteira abre o cadastro; ações secundárias no detalhe |
| “Cadastrar” no menu + header + rodapé | Um CTA principal na home; cadastro não compete no menu |
| “Simular entrada/saída” como ação principal | Removido; exemplos em “modelo dos cards” |
| Jargão admin (StatusBadge ativo, “validar fluxo”) | Linguagem da família |

## IA do menu

1. **Meus dependentes** — cadastro e edição  
2. **Avisos** — histórico/prévia de entrada e saída  
3. **Como funciona** — ajuda  

## Fluxos validados

1. Login → home de dependentes  
2. Cadastrar (nome) → detalhe → editar  
3. Avisos (filtro por filho) → ver modelos de card  
4. Como funciona → links claros para as duas áreas
